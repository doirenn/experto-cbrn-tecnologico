# Experto global en emergencias tecnológicas, CBRN e infraestructura crítica

Sistema mixto: skill + catálogo + investigación en vivo. El catálogo dice a quién preguntar. Las fuentes oficiales del día dan el dato.

Cubre accidente químico, radiológico, nuclear, industrial, presa, relaves, apagón e infraestructura crítica. No sustituye al experto en desastres naturales, al de salud pública ni al de voluntarios.

## Cómo usarlo

Pregunta en el chat de este proyecto. El agente debe leer el skill y el playbook.

Ejemplos: sitrep de un accidente industrial; perfil de regulador de Japón, Nigeria o Brasil; si hay notificación IAEA o INES; quién manda un derrame en Nigeria (NOSDRA, no EPA); cruce sismo + refinería.

Claude Code y claude.ai son un addon: [USO-CLAUDE.md](USO-CLAUDE.md).

## Reglas

Cobertura mundial. Nombres oficiales en idioma local. Citar. No inventar INES ni roturas. Español latino neutro.

## Límites

Los nombres de reguladores y las URL cambian. Verificar el sitio nacional y el de IAEA u OPCW. Este proyecto no reemplaza a EXPERTO DESASTRES NATURALES, EXPERTO SALUD PUBLICA ni EXPERTO VOLUNTARIOS.
