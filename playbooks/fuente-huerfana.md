# Fuente huérfana y radiológico sin reactor

Usar ante hallazgo o accidente de fuente, no ante un reactor.

## Pasos

1. Regulador radiológico del país. No copies NRC.
2. ¿Hay comunicado oficial del hallazgo? Si no, rumor.
3. IAEA solo si el Estado notifica o pide asistencia.
4. Clínica: [cruce-salud.md](cruce-salud.md). No recetes.
5. Cero instrucciones de búsqueda, de apertura o de manipulación.

## Plantilla

```

## Regulador
```
