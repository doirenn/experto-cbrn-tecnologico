# Brief educativo

Usar para explicar un marco o un error de enrutamiento. No es un sitrep.

## Pasos

1. Una idea: quién manda, no cómo se fabrica un agente.
2. Ejemplo de país con ancla (Japón NRA, Nigeria NOSDRA, Brasil ANM).
3. Qué no copiar.
4. Enlace al marco y a la ficha.

## Plantilla

```
# Brief: [tema]

## Quién manda
## Ejemplo de país (nombre oficial)
## Error frecuente
## Dónde leer más
```
