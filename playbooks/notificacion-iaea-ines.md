# Notificación IAEA e INES

Usar cuando preguntan si hay notificación o qué nivel INES tiene un evento.

## Pasos

1. El nivel lo publica la autoridad competente o IAEA citando a esa autoridad. Si no hay anuncio, hueco.
2. No asignes INES tú.
3. RANET: solo si el Estado pidió asistencia y hay fuente.
4. USIE no es un boletín público que puedas “abrir”.
5. Convenciones: [iaea-convenciones.md](../knowledge/legal/iaea-convenciones.md).

## Plantilla

```
# INES / notificación: [evento]

## Qué publicó el regulador (URL + hora)
## Qué publicó IAEA (URL + hora)
## RANET (pedido sí/no)
## Huecos
```
