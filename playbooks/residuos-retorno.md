# Residuos y retorno a la zona

Usar cuando preguntan si se puede volver, qué se hace con escombros o quién levanta la exclusión.

## Pasos

1. Quién publicó la zona: regulador o NDMO.
2. Quién autoriza residuos: [residuos-escombros.md](../knowledge/systems/residuos-escombros.md).
3. No inventes un radio ni una fecha de retorno.
4. PDNA: desastres. Clínica de retorno: salud.
