# Cruce con salud pública

Heridos, hospitales, EMT y descontaminación clínica no se operan aquí. EXPERTO SALUD PUBLICA manda el tramo sanitario.

## Pasos

1. Este repo: sustancia, instalación, regulador, zona de exclusión.
2. Salud: MoH, hospitales, EMT, IPC, MHPSS. No recetes. No diagnostiques.
3. Biológico como brote o PHEIC: entrega el evento a salud. Aquí solo si es laboratorio, toxina o arma.
4. WHO REMPAN es mapa sanitario de radiación, no el regulador nuclear.

## Plantilla

```
# Cascada sanitaria: [evento tech] en [lugar]

## Tramo regulador (este repo)
## Tramo MoH / EMT (EXPERTO SALUD PUBLICA)
```
