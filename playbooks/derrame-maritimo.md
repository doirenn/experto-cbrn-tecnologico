# Derrame marítimo

Usar ante hidrocarburo o HNS en mar o costa. No es EPA salvo que el evento sea en EE.UU.

## Pasos

1. Autoridad nacional de derrames (NOSDRA, marítima, ambiente).
2. ¿Mediterráneo? REMPEC como mapa. ¿Golfo de Guinea? GI WACAF como mapa. El Estado manda.
3. Volumen: solo sitrep oficial.
4. IOPC: [iopc-derrames.md](../knowledge/legal/iopc-derrames.md) si el usuario pregunta quién paga.
5. Pesca: [pesca-derrame.md](../knowledge/personas/pesca-derrame.md).

## Plantilla

```
# Derrame: [lugar]

## Autoridad
## Qué está publicado (volumen, costa)
## Red regional (sí/no)
## Cruce salud / desastres
## Qué no afirmar
```
