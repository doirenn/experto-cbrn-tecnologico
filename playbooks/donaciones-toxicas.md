# Donaciones tóxicas

Usar cuando quieren enviar yodo, trajes, detectores o “kits CBRN”.

## Pasos

1. Lista del Estado o no enviar.
2. Yodo y EPP sin pedido oficial: no.
3. Matching de voluntarios: EXPERTO VOLUNTARIOS. Clínica: salud.
4. Hermano de cash (pendiente) para el oficio de donaciones. Aquí el veto sectorial.

## Plantilla

```
# Donación: [qué] a [dónde]

## ¿Hay lista oficial?
## Qué no enviar
## A quién preguntar (regulador / MoH)
```
