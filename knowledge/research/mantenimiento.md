# Mantenimiento

El catálogo se pudre. Trátalo como mapa con fecha.

## Cada ficha de país

Oleada implícita 2026-08. Al tocar una ficha, actualiza la fecha en `anclas.md`.

## Cada trimestre o tras un accidente mayor

1. Probar URLs de anclas (NRA, ASNR, CNEN, ANM, NOSDRA, BAPETEN, SNRIU, AERB, NNR, FANR, ONR, ARN).
2. Añadir el evento a `knowledge/cases/` si enseña un error de enrutamiento.
2. Verificar nombres vigentes (fusiones de reguladores, ejemplo Francia ASN/IRSN).
3. No inventar NAA, INES ni partidos TEIA para “completar” el ISO.

## No hacer

Rellenar campos vacíos con NRC, EPA o Seveso.
