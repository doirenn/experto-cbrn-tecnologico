# Glosario corto

Términos de mapa. No son definiciones legales recitadas.

| Término | Uso aquí |
| --- | --- |
| CBRN | Químico, biológico (laboratorio/arma), radiológico, nuclear. No es un brote comunitario. |
| INES | Escala internacional de eventos nucleares y radiológicos. La publica la autoridad, no el analista. |
| RANET | Red de asistencia IAEA. A pedido del Estado. |
| IEC | Incident and Emergency Centre de IAEA. |
| USIE | Canal unificado de intercambio de información de emergencias IAEA. Verificar acceso: es interestatal. |
| NAA | National Authority de la CWC (OPCW). |
| TEIA | Convención UNECE de accidentes industriales transfronterizos. |
| Natech | Amenaza natural que dispara accidente tecnológico. |
| Relaves | Presa o depósito de jales / estériles mineros. |
| Zona caliente | Área de exclusión del Estado. Cero SUV. |
| Seveso | Régimen UE. No es ley mundial. |
| OPRC | Convenio IMO de cooperación ante derrames. |
| HIP 5 / HIP 7 | Tipos UNDRR-ISC químico y tecnológico. Aquí son primarios. En desastres son cascada. |
| EPZ | Emergency Planning Zone u otro nombre local. El decreto nacional manda. No inventes el radio. |
| GISTM | Estándar industrial de relaves. No es ley nacional. |
| IOPC | Fondos de indemnización por derrame. Solo Partes y casos que entren. |
| Sûreté | Accidente y fallo. Distinto de security (acceso). Aquí no se opera security. |
